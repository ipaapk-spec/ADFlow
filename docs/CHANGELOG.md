## 0.8.3 — 图片详情支持键盘翻图（2026-10-28）

- 图片详情里 `←` / `→` 切换上一张、下一张，空格等于下一张；到头会绕回另一端。
- 翻图范围就是打开处当前的顺序：图库（含搜索 / 已赞筛选）、素材库、生成台本次结果；详情头部显示 `3 / 14`，图片两侧有箭头按钮。

- 图库 / 素材库改成 `AssetGrid` 统一持有详情，卡片只负责展示；在卡片上删掉的图不会再出现在切换列表里。

## 0.8.0 — 图库 / 素材库 + 裁剪（2026-10-28）

## 0.7.0 — 视频生成（2026-10-28）

- 新增 `/video` 页面与导航入口，接入 Agnes Video 2.5 Flash（720P，限免）和 Agnes Video 2.5（720P / 1080P / 1K / 2K，按秒计费）。
- 支持文生视频，以及填写公网首帧图片 URL 的 keyframe 生成；时长 4–12 秒，六种画幅。
- 视频任务走异步队列：`POST /v1/videos` 创建，`GET /agnesapi` 轮询，完成后下载 mp4 入库。
- `/api/files` 增加 mp4 MIME 和 Range 支持，视频可播放、可拖进度条；视频存 `data/videos/`，不混入图片素材库。
- 任务页、设置页、统计和用量补上视频模型与视频占用；图片生成台不展示视频缩略图。
- 上游视频队列满时返回「视频队列已满，请稍后重试」，页面可重试。

## 0.6.0 — 接入 Agnes 图像模型（2026-10-28）

- 新增 Agnes 档位：`agnes-image-2.5-flash`，走 `POST /v1/images/generations`，默认 2K（1:1 为 2048×2048），当前限免，成本记 ¥0。
- 支持文生图、图生图和多图合成；参考图以 Data URI 直传上游，不依赖公网地址。
- 成图直接要 Base64 返回，省掉二次下载存储域图片（服务器网络环境下这一步容易超时）。
- Agnes 是同步接口，队列里直接生成并入库，不参与 RunningHub 的 taskId / 轮询。
- 环境变量优先 `AGNES_URL` + `AGNES_KEY`（国际站），回退 `AGNES_BASE_URL` + `AGNES_API_KEY`（国内站）；未配置时该档位自动隐藏。
- Agnes 不支持 4:5，选 4:5 时按最接近的 3:4 出图；区域重生成 / 扩图仍使用 RunningHub 档位。
- UI 对 ¥0 的档位显示「限免」。

## 0.5.0 — 模型扩容 + 人民币计价（2026-10-28）

**发现**：RunningHub 目录里的模型名（`nano-banana-2-lite/...`）不是调用路径，真实路径在 SKU 详情的 `rhEndpoint` 字段。用 `/api/sku/list` 拉全 425 个 SKU，得到 99 个图片 endpoint 及其人民币价格。

**结果**：当前 Key 实际可调用 5 个模型（其余 94 个返回 1007 无权限）：
nano-banana 2 lite、nano-banana 1、seedream v5 lite、gpt-image-2.0（仅文生图）、nano-banana 1 稳定版（仅图生图）。

**改动**：
- 模型从 2 个扩到 5 个，按能力过滤：文生图隐藏仅图生图模型，上传参考图后隐藏仅文生图模型。
- 成本记录改为人民币精确记账（新增 `cost_cny` 列，旧数据按 7.2 折算），去掉汇率设置与美元换算。
- 设置页展示每个模型的价格、能力与对应 endpoint。
- README 补充 1001/1007 的区别与加模型的方法。

## 0.4.0 — 区域重生成 + 扩图（2026-10-28）

先说实验结论：给 RunningHub 的 image-to-image 传 `maskUrl` / `mask`，接口照收不报错，但对照实验（同一张图、同一句「转黑白」）显示加不加 mask 结果一致，**遮罩被忽略**。所以没有依赖上游遮罩，改为本地合成：

- **区域重生成**：画刷选区 → 按选区外扩 35% 裁一块上下文图 → 上传重画 → 用遮罩 alpha 做 6px 羽化，把结果贴回原图原位置，其余像素不动。接口 `POST /api/inpaint`。
- **扩图**：按目标比例算画布（保持原图一边不变），四周用镜像条带 + 模糊底铺满，交给模型补全；再把原图区域带羽化边贴回中心，保证主体不变形。接口 `POST /api/outpaint`。
- 详情弹层新增「区域重生成」「扩图」入口；任务列表给这两类任务加了标签。
- 深链：`/library?asset=<id>&edit=1` 直接打开某张图的选区编辑器。

已知限制：扩图四周质量取决于模型的补全能力，lite 档容易补成模糊背景，建议用均衡档或写更具体的补充描述。

## 0.3.0 — P1 交付能力（2026-10-28）

- **预设管理**：把「模型 + 比例 + 数量 + 提示词 + 负向词」存成预设，一键回填；支持删除。
- **深链**：`/library?asset=<id>` 直接打开某张图的详情弹层。
